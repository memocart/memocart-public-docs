O MemoCart guarda carrinhos de produtos com o contexto do porquê de cada item. Coleções agrupam esses produtos, e um link de compartilhamento deixa outra pessoa abrir o carrinho.

O foco é AI-first: agentes usam a API e pessoas abrem os links. O produto tem extensão de navegador e uma API REST em [api.memocart.link](https://api.memocart.link).

A [API Reference](/api/) é gerada do OpenAPI versionado neste repositório. Ela descreve o contrato publicado, sem endpoints além dos que estão nesse arquivo.
