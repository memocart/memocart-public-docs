## Criar uma conta

Abra [memocart.link](https://memocart.link) e crie uma conta.

## Extensão do navegador

A extensão para Chrome ainda não está na Chrome Web Store. O link de instalação entra nesta página quando a publicação sair.

## API

A [API Reference](/api/) sai de `openapi/openapi.json`, a cópia versionada de [api.memocart.link/openapi.json](https://api.memocart.link/openapi.json). O build do site lê esse arquivo e não baixa a especificação de novo.
