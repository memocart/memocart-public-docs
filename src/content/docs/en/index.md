MemoCart stores product carts with the context for why each item is there. Collections group those products, and a share link lets someone else open the cart.

The product is AI-first: agents use the API, and people open the links. There is a browser extension and a REST API at [api.memocart.link](https://api.memocart.link).

The [API Reference](/api/) is generated from the OpenAPI file versioned in this repository. It describes the published contract and does not add endpoints beyond that file.
