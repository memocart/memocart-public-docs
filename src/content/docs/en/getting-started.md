## Create an account

Open [memocart.link](https://memocart.link) and create an account.

## Browser extension

The Chrome extension is not on the Chrome Web Store yet. The install link will be added to this page when it is published.

## API

The [API Reference](/api/) is built from `openapi/openapi.json`, the versioned copy of [api.memocart.link/openapi.json](https://api.memocart.link/openapi.json). The site build reads that file and does not download the specification again.
